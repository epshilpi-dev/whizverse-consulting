# Whizverse Consulting Static Website

## Files
- index.html — Home
- about.html — About / Why Us
- projects.html — Services / Industries
- contact.html — Contact form
- css/style.css — Responsive styling
- js/script.js — Mobile navigation + static mailto contact form
- images/logo.png — Logo image
- images/profile.jpg — Placeholder asset

## Run locally
Open index.html in a browser, or use VS Code Live Server.

## Important
The contact form is intentionally backend-free. Submitting it opens the visitor's email client with a prepared message to:
contact@whizverseconsulting.com

For a fully hosted form that works without an email client, connect the form to a service such as Formspree later.

## Cloudflare Pages
1. Create a GitHub repository and upload this folder.
2. In Cloudflare Pages, connect the GitHub repository.
3. Deploy as a static site; no build command is required.
4. Add your GoDaddy domain under Custom Domains.
